    변환할 이미지 선택

    기존 C2PA 서명이 신뢰되는 JPEG 또는 PNG · 최대 20 MB

    현재 변환은 로컬 실험용 신뢰 정책을 사용합니다. 결과 M1은 Classic ES256으로 서명되고, P1 증거에 ML-DSA-65가 적용됩니다.

    변환 전에 확인하세요

    • 처음부터 C2PA 기록이 없는 사진에는 M0가 없어 변환할 수 없습니다.
    • 기존 서명이 손상되었거나 이 실험용 신뢰 목록에서 확인되지 않으면 변환이 중단됩니다.
    • 완성된 이미지는 최종 검증을 통과한 경우에만 내려받을 수 있습니다.

    C2PA란 무엇인가요?

    C2PA는 콘텐츠의 제작·편집 정보를 검증 가능한 자격 증명으로 연결하는 기술 표준입니다. 파일에 연결된 Manifest에는 출처, 작업 이력, 서명 정보가 담길 수 있습니다.

    무엇을 확인하나요?

    서명과 파일 결합, Manifest의 출처 연결, 기록된 편집 작업을 확인합니다.

    ◇

    메타데이터는 어떻게 읽나요?

    일반 EXIF 정보와 서명된 C2PA Assertion을 구분해 보여줍니다. 결과의 구조 그림에서 관계를 확인할 수 있습니다.

    !

    결과의 한계는 무엇인가요?

    C2PA가 없다는 이유만으로 가짜는 아닙니다. 서명 검증도 콘텐츠의 사실 여부나 소유권을 보증하지 않습니다.

    자주 묻는 질문

    AI 생성 여부를 자동으로 판정하나요?

    Manifest에 기록된 AI 생성 선언을 보여줍니다. 독립적인 AI 탐지 결과와 구분해서 읽어야 합니다.

    C2PA 정보가 없다면 변조된 파일인가요?

    아닙니다. 애초에 자격 증명이 없거나 유통 과정에서 제거되었을 수 있습니다.

    업로드한 파일은 어디에서 처리되나요?

    기본 검증은 이 사이트의 로컬 서버에서 처리합니다. 브라우저 검증 모드를 켜면 파일은 서버로 전송되지 않습니다. URL 검증은 서버에서만 수행됩니다.

    검증 결과 읽는 법

    파일을 확인하고, 상태와 근거를 읽고, 필요한 보고서를 저장하는 순서로 사용하세요.

    01

    파일 또는 URL 선택

    파일을 올리거나 공개 HTTPS 파일 주소를 입력합니다. 민감한 파일은 개인정보 설정에서 브라우저 검증을 켤 수 있습니다.

    02

    상태와 오류 확인

    신뢰 확인·유효·검증 실패·C2PA 없음은 서로 다른 의미입니다. 검증 항목 탭에서 실패 코드를 우선 확인하세요.

    03

    출처와 구조 살펴보기

    출처 이력, Manifest, 구조 그림과 일반 메타데이터를 구분해 읽습니다. AI 생성 여부는 기록된 선언으로 표시합니다.

    04

    결과 저장

    PDF·JSON·HTML 보고서를 받을 수 있습니다. 여러 파일을 분석했다면 아래 비교 기능으로 차이를 확인하세요.

    상태별 해석

    신뢰 확인

    서명과 파일 결합이 유효하고 선택한 신뢰 목록에서 서명자를 확인했습니다.

    유효 · 신뢰 미확인

    서명은 유효하지만 선택한 목록에서 서명자의 신뢰는 확인되지 않았습니다.

    검증 실패

    변조, 서명 또는 기타 검증 오류의 세부 코드를 확인해야 합니다.

    C2PA 없음

    Manifest가 없다는 뜻입니다. 이것만으로 가짜라고 판단할 수 없습니다.

    연구·사용 가이드라인

    • 동일한 원본 파일의 형식, 크기와 해시를 함께 기록하세요.
    • Manifest 존재, 파일 무결성, 서명자 신뢰를 분리해서 읽으세요.
    • EXIF 같은 일반 메타데이터를 서명된 Assertion과 혼동하지 마세요.
    • AI 선언은 독립적인 AI 탐지 결과가 아닙니다.
    • 서명 검증은 사진 속 장면의 사실 여부나 소유권을 단독으로 증명하지 않습니다.
    브라우저 검증: 파일당 최대 100 MB · 서버 검증: 파일당 최대 500 MB. URL 검증과 AI 이미지 생성은 서버 연결이 필요합니다.
