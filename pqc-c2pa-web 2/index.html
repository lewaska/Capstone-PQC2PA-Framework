03 / RESEARCH GUIDELINES

실험 가이드라인

비교 가능한 기록을 남기고 결과를 과장하지 않기 위한 기준입니다.

입력 조건 기록

파일 형식과 크기, 촬영·편집·내보내기 조건을 함께 기록해 같은 조건에서 비교합니다.

검증 상태 분리

Manifest 존재, 무결성, 서명, 신뢰 상태를 각각 표시합니다. 미검사 항목은 성공으로 표시하지 않습니다.

알고리즘 명시

기본 C2PA와 SHA3-256·ML-DSA 연구 확장을 구분하고, 판정에 사용된 알고리즘을 결과에 남깁니다.

04 / QUESTIONS

자주 확인하는 내용

C2PA 정보가 없으면 조작된 이미지인가요?

아닙니다. 파일을 만든 기기나 편집·공유 과정에서 출처 정보가 기록되지 않았거나 제거되었을 수 있습니다.

AI 생성 선언은 AI 탐지 결과인가요?

아닙니다. Manifest에 기록된 선언을 보여주는 것입니다. 선언이 없다고 사람이 만든 이미지라고 확정할 수도 없습니다.

‘신뢰 확인’이면 이미지 내용도 사실인가요?

아닙니다. 출처 기록과 서명 검증은 이미지 속 장면의 사실 여부를 직접 증명하지 않습니다.

왜 원본 이미지는 기록에 남지 않나요?

검사 실행 후 브라우저 화면의 파일 참조와 미리보기를 해제하도록 설계했습니다. 기록에는 파일 정보와 상태만 남깁니다.

01 / BROWSER

브라우저에서 Manifest 읽기

npm install @contentauth/c2pa-web 설치 후 Vite 환경에서 실행합니다. 공식 @contentauth/c2pa-web 문서의 Reader 흐름을 바탕으로 작성했습니다.

JavaScript · 읽기 예제
import { createC2pa, Reader } from '@contentauth/c2pa-web';
import wasmUrl from '@contentauth/c2pa-web/resources/c2pa.wasm?url';

const engine = await createC2pa({ wasmSrc: wasmUrl });

export async function readImageCredentials(file) {
  const reader = await Reader.fromBlob(engine, file.type, file);
  try {
    return await reader.manifestStore();
  } finally {
    await reader.free();
  }
}
